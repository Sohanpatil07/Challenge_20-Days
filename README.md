# 20 Days Coding Challenge 🚀

Welcome to the **20 Days Coding Challenge**! 🎉 This challenge is designed to help you sharpen your coding skills, explore new concepts, and build consistency in programming. Let's make coding a fun habit together! 😄

---

## 🗓 Challenge Overview

- **Duration:** 20 days
- **Goal:** Complete one coding task every day.
- **Focus Areas:** Problem-solving, algorithms, data structures, and real-world projects.

---

## 📜 How It Works

1. Fork this repository and clone it to your local machine.
2. Check out the `DayX/README.md` for each day's challenge.
3. Solve the challenge and update the respective folder with your solution.
4. Commit your changes daily and push them to your GitHub repo.
5. Share your progress with the community using #20DaysCodingChallenge!

---

## 🗂 Folder Structure

```
📂 20DaysCodingChallenge
 ├── Day1
 │   ├── README.md (description of the challenge)
 │   └── solution.ext (your solution file)
 ├── Day2
 │   ├── README.md
 │   └── solution.ext
 └── ...
```

---

## ✨ Daily Workflow

1. **Read the Challenge:**
   Navigate to the `DayX/README.md` file and understand the task.

2. **Solve the Problem:**
   Implement your solution in the respective `solution.ext` file.

3. **Test Your Code:**
   Ensure your solution works correctly with test cases.

4. **Commit and Push:**
   ```bash
   git add .
   git commit -m "Completed Day X Challenge"
   git push origin main
   ```

## 🎯 Challenge Topics

Here are some topics you'll encounter:

- Day 1-5: Basics of programming (loops, conditions, arrays)
- Day 6-10: Algorithms and problem-solving
- Day 11-15: Data structures (stacks, queues, trees)
- Day 16-20: Real-world coding challenges and mini-projects
